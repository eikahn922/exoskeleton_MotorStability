# Shared Exoskeleton Components

These six unchanged files appeared byte-for-byte in multiple testing and final source archives. They are stored once here to keep the repository free of redundant CAD binaries:

- `FlapTop.SLDPRT`
- `Hinge.SLDPRT`
- `Hip_Lever_V2.SLDPRT`
- `RS02.step`
- `strap (1).SLDPRT`
- `ThighBar.SLDPRT`

SolidWorks may request this folder when opening either full-exoskeleton assembly.
