# 01 — Testing

The testing phase was a fast CAD-based evaluation of strap placement and apparent stability. It did not use quantitative sensors or formal acceptance thresholds.

## Evaluation criteria

- visible movement of the motor-holder region;
- apparent improvement in support when the strap was added;
- strap routing around the leg;
- clearance from surrounding exoskeleton components; and
- ease of repositioning the attachment during rapid iteration.

## Folder order

1. [Focused Strap Placement Test](01%20-%20Focused%20Strap%20Placement%20Test/README.md) — isolates the motor-support/pelvis-bar region for quick attachment changes.
2. [Full Exoskeleton Test Context](02%20-%20Full%20Exoskeleton%20Test%20Context/README.md) — places the updated test geometry into the complete assembly.

Each folder contains all components supplied with its source ZIP. Some files intentionally overlap between the focused and full-context packages so either assembly can be opened independently.

The similarly named attachment parts and subassemblies are not assumed to be interchangeable. Their test-package versions are kept with the assemblies that originally used them.
