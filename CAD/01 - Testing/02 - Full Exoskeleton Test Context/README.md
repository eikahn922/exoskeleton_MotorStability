# Full Exoskeleton Test Context

Open:

`OPEN - Full Exoskeleton Test Context.SLDASM`

This assembly places the updated strap-placement test into the full exoskeleton. Its purpose is to inspect leg routing, surrounding clearances, and the relationship between the temporary motor support and the remaining system.

`Assembly Components/` contains all ten dependencies supplied with the full test package, including the updated test subassembly, attachment geometry, strap, test hip bar, and surrounding exoskeleton parts.

If SolidWorks asks for a dependency, point it to the local `Assembly Components` folder and allow the resolved path to update.
