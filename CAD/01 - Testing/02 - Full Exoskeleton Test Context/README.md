# Full Exoskeleton Test Context

Open:

`OPEN - Full Exoskeleton Test Context.SLDASM`

This assembly places the updated strap-placement test into the full exoskeleton. Its purpose is to inspect leg routing, surrounding clearances, and the relationship between the temporary motor support and the remaining system.

`Assembly Components/` contains the test-specific full-context components and the updated test subassembly. Unchanged exoskeleton parts are stored in `../../03 - Shared Exoskeleton Components/`; the shared test bar is stored in `../Shared Test Component/`.

If SolidWorks asks for a dependency, point it to those component folders and allow the resolved path to update.
